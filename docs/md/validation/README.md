# 优化与验证记录

本次修改覆盖依赖图读取和构建、缓存、后台任务、菜单操作、声明修改、设置、文档和 CI。

## 已落地

- sbt DOT 输出使用线性读取路径；复杂子图等语法保留 Graphviz 回退。直接边只建立一次索引，节点编号按图分配。
- 使用迭代构树、路径环检测和明确的展开预算，避免递归栈溢出或无限展开。保留共享依赖的每条使用路径，未用全局 visited 删除合法路径。
- DOT、声明和大小数据按项目管理，项目级监听在分析页关闭后仍负责导入失效；DOT 缓存有容量限制，校验文件元数据、用户 TTL 和失效代次，失效前启动的解析不能重新填入旧缓存。TTL 为 0 时禁用图缓存。
- 模块/Scope 发现不再触发依赖分析；已导入但未聚合的模块可单独查询名称。已分析模块按 TTL 复用，生成 Scope 由设置控制。
- 普通刷新只重新分析；SNAPSHOT 刷新在后台执行，对当前模块设置临时参数，并仅清理本次加入的 session 设置。
- 筛选防抖并在后台计算，跳过过期结果；错误、取消和关闭时结束加载状态，错误通知提供重试。
- JAR 大小按需后台计算、复用坐标大小，合计按已解析坐标去重；引用树默认只展开有限层级。
- 菜单区分直接依赖删除和从父声明排除，校验版本、Scope、项目类型及有效声明。存在多个修改候选时选择声明，写入前展示前后对照，并再次验证文件未被修改。
- 声明通过专用 DataKey 和智能 PSI 指针保存，标准 PSI_ELEMENT 返回有效 PSI 元素；配置导航沿当前依赖的模块链定位。
- 设置面板支持国际化、输入校验和资源释放；快捷键文档与 macOS 的 Ctrl+Shift+L 注册一致。
- 修复增量分发包遗漏新增内部类和保留已删除类/库的问题；新增生产 JAR 与全部编译类逐字节比较的回归测试。
- 删除显式 Logback 和反射兼容依赖；签名默认关闭，使用命名明确的发布环境变量。CI 执行实际的插件兼容性验证。

## Go to / Exclude 与模块匹配补充

- 依赖解析按 `%`、`%%`、`%%%` 的 PSI 操作数读取 group/artifact/version，支持常量与别名、括号、泛型序列、序列拼接、结果块、配置映射和方法修饰；不再通过字符串出现顺序推断坐标。循环引用有路径与深度保护。
- Go to 跳转定义，Exclude 修改使用位置；同一个 `ModuleID` 被多处引用时不删除其共享定义。共享有序依赖序列在当前模块引用处按组织、名称、版本、配置和交叉版本匹配，使用 `filterNot`/`map` 修改；无序或无法完整解析的集合仅导航，计算型工厂不会凭参数猜测。删除 `.settings(...)` 或序列中的条目时处理相邻逗号和注释。
- 版本精确匹配优先；遇到淘汰、动态版本等情况按坐标和配置回退。多个候选用带文件位置、Scope 和表达式摘要的下拉框选择，修改继续保留预览与过期检查。
- sbt project ID 来自导入模型；`moduleName` 通过各项目的 scoped 命令获取，覆盖未聚合项目。IDEA 显示名、目录名和发布 artifact 名分开处理，不再切割限定显示名、替换空格或全文搜索任意字符串。平台映射使用导入的 JVM/JS/Native 信息；坐标有歧义时不任意取 Map 中首项。
- 声明归属按显式 `Project(id, ...)`、project 绑定及 crossProject 平台投影匹配，区分公共与平台 settings、项目 scoped key 和 ThisBuild。扫描项目目录内的多个 `.sbt` 文件，并通过引用解析访问共享声明。
- 新增 `DeclarationMatcherSpec`、`SbtModuleIdentitySpec` 共 14 项普通单测；真实 PSI 测试在独立临时 IDEA 项目中运行。`sbt psiTest` 已接入 CI。

## 右键菜单补充回归

排查确认 Go to 仍会被平台父类隐藏：多个匹配声明需要选择器，但 `getNavigatable` 只能返回单个目标，返回 null 后父类同时关闭 enabled/visible；原实现只重新设置 enabled。现在直接按 sbt 依赖上下文设置可见性，再按索引和声明状态设置可用性。Go to 与 Exclude 在索引中或没有适用声明时保留灰色动作和原因描述；其他构建系统不显示这些 sbt 动作。

依赖树与 usages 树在右键按下、释放时先选中点击行，空白位置清除选择，再由原有 PopupHandler 创建菜单。列表和树的 DataSink 从实际选中行读取依赖与 variants，不沿用已经变化的共享选择状态；树模型跳过没有 DependencyGroup 的占位节点。

新增隔离运行时回归覆盖多候选动作可见性、缺少声明、非 sbt 上下文切入/恢复、Exclude 无可修改声明时的可见性，以及依赖树/usages 树右键换行、空白清选、列表/树 DataSink 取数。动作可见性测试使用真实 PSI 声明作为候选 fixture；它不替代真实项目导入矩阵。该轮结果为 46 项普通测试、29 项隔离 IDEA 检查通过，格式检查和 Plugin Verifier 通过。

## 右键动作置灰与跨平台模块状态补充修复

- 支持 `withSources ()` 等中缀、后缀修饰写法，保留整个使用表达式供预览和修改。
- 优先精确配置匹配，再按 sbt 的 Compile → Runtime → Test 继承关系寻找声明；传递依赖没有独立源码时，Go to 定位引入它的直接声明。

- 共享声明从物理 AST 读取，避免 Scala stub 返回 `dummy.scala` 临时表达式，保证跨文件 Go to 打开真实定义。
- 跨平台模块按 sbt selector 聚合 JVM/JS/Native 证据，聚合父模块的默认 JVM 值不会覆盖子源集的平台；平台冲突保留歧义，不任意选择。IDE 模块映射失败时保留 DOT artifact 和解析状态，不再错误标记为 unresolved；真实未解析状态继续保留。

## sbt shell 启动时的 Write-unsafe context 补充修复

Scala 插件的 shell 启动流程使用默认 `invokeAndWait` 切回 EDT，在写操作中调用 `saveAllDocuments`。默认 modality 会继承调用线程的进度上下文；若是 `ANY`，即使实际窗口状态是 `NON_MODAL`、也已经持有写锁，保存仍不属于 write-safe 调用。

- 普通输出命令和 DOT 命令统一通过 `SbtTaskRunner.submit` 提交。`SbtShellCommandExecutor` 在独立后台线程中建立明确的非模态进度上下文，阻止继承的 `ANY` 传到 shell 启动保存；shell 启动与命令等待均不占用 EDT。
- 独立进度指示器转发父任务取消与项目关闭检查，生命周期不会停止或修改父进度。同步启动异常和异步命令异常均传回调用者，拒绝从 EDT 或持有读锁时提交。
- 新增 3 项隔离 IDEA 回归：验证原 ANY 回调不可写、新入口使用 Scala 实际的默认 `invokeAndWait` 与真实写操作/保存 API 后可写；同时验证进度上下文恢复、取消、项目关闭、线程/读锁限制和错误传播。回归使用命令工厂夹具，不将其表述为启动完整 sbt 进程的 UI 测试。
- 本轮 59 项单测、73 项 IDEA 检查、格式检查和生产 Option ABI 检查通过。Plugin Verifier 结果 Compatible，报告 19 处弃用、31 处实验性和 17 处内部 API 引用；内部引用计数包含 shell 调用移入新闭包后的报告变化。

## Circe 多模块菜单补充修复

- Circe 通过辅助函数生成 `Project` / `CrossProject`，绑定名称和实际 sbt ID 不总是一致。现以导入的构建 URI、sbt ID 和 base directory 为依据，沿可静态识别的辅助函数及字面量路径定位声明；不执行构建代码，也不硬编码 Circe 函数名。
- 条件依赖集合分别解析 then/else 中的物理源码，保留每条声明的导航和修改位置；聚合模块从相同 sbt selector 的源集取得平台信息，避免 JS/Native 误用 JVM 设置。
- 新增六项隔离 IDEA 回归，覆盖工厂创建的多模块、CrossProject、条件依赖、平台目录、歧义和动态函数拒绝。普通模块、CrossProject 和条件分支验证生产动作启用、删除/排除、再次解析、相邻模块保留及 Undo/Redo。
- 另以 Circe 实际构建文件的临时副本验证 core、jawn、generic（JVM/JS/Native）、benchmark 六组模块/平台的定位、可编辑状态、删除计划与修改后语法/再次解析，检查体耗时 2.912 秒。未修改原工程。
- 最新结果为 59 项单测、79 项 IDEA 检查通过，检查体分别耗时 1.930 秒和 15.211 秒；格式、生产 Option ABI 和 Plugin Verifier 通过，兼容性提示数量维持 19 / 31 / 17。

## 项目模块节点禁止删除和排除

项目模块节点不等同于 `libraryDependencies` 中的外部库声明。此前模块坐标可能缺少组织名，仍被作为库依赖参与排除，最终在转义字符串时触发空指针。Remove / Exclude 现在先校验节点类型及完整库坐标，模块节点保持置灰并说明不支持修改项目模块依赖；执行动作时重新校验，编辑计划也拒绝 null、空字符串和空白坐标。源码导航逻辑保持独立。

回归覆盖根模块、直接/传递模块、缺少导入元数据、各坐标字段为空或空白、直接调用禁用动作，以及切换回有效库后的恢复。所有被拒绝的操作均断言源码未变化。本轮 59 项单测、80 项 IDEA 检查通过，检查体分别耗时 2.148 秒、23.517 秒；新增限制用例耗时 11.39 毫秒。

## moduleName 聚合结果复用

- 优先查询当前构建及其他构建的入口项目，一次收集聚合输出中的所有项目名称；按完整构建 URI 和 sbt 项目 ID 记录结果，已有项跳过，只补查缺失或未聚合模块。沿用 sbt 的真实生效值，不执行 `set`、不改变项目选择或聚合设置。
- 逐条关联作用域标题与值，识别本地 ID、完整 selector、外部 `ProjectRef(uri(...), id)` 及当前项目的无前缀标题。不再使用最后一行猜测被查询项目；同名平台项目分别保留，缺失或冲突结果明确拒绝。
- 新增 12 项单测，包括匿名化真实控制台回放：48 条原始查询缩减到 6 条，保留全部 48 个项目身份，减少 87.5% 的插件查询命令。这是日志回放的命令数比较，不是 Circe 整体刷新耗时基准。sbt 自身的聚合仍可能输出已有子项目，插件会复用这些结果。
- 2026-10-27 最新验证：71 项单测、80 项 IDEA 检查通过，检查体耗时分别为 1.764 秒及 12.735 秒；真实 sbt 夹具通过，耗时 27.55 秒，验证聚合名称、未聚合模块、同名外部构建、平台同名、七份 DOT、Runtime 依赖及原 session 设置保留。

多独立构建仍受 Scala 插件单活动 shell 的限制；通过 RootProject/ProjectRef 加载的外部构建使用完整 URI 引用分析，未在活动 shell 中加载的独立链接构建会被拒绝，防止展示错误构建的数据。图模型仍按使用路径展开，超过 512 层或 100,000 条展开路径会明确停止，而不是静默裁剪依赖。
